# Submissions

Each team puts its work in its own folder in its fork, and opens **one Pull Request** into `main`.

```
submissions/
  <team-name>/
    README.md          what you built, for whom and why; how to run it; which LLM (if any) and where
    templates/         your explanation templates and decision files (data, not code)
    src/               your prototype (any language)
    tests/             tests for your rules and templates
    examples/          motiveringen your prototype produced, for fictional cases only
    LICENSE            only if you use a licence other than the repo defaults
```

The structure is a suggestion; the PR template checklist is what counts.
