# Glossary

Dutch terms and acronyms used in this repository.

| Term | Meaning |
|---|---|
| **Afleidingsregel** | Derivation rule: how the algorithm gets from registered data to an outcome. RvIG publishes them as Gherkin specifications. |
| **Algoritmeregister** | The Dutch government's public register of algorithms, [algoritmes.overheid.nl](https://algoritmes.overheid.nl/nl). |
| **Awb** | Algemene wet bestuursrecht, the General Administrative Law Act. |
| **Bestuursorgaan** | Administrative body that takes a decision, for example the municipality. |
| **Besluit** | A decision by an administrative body, for example on an application. |
| **Bezwaar** | Objection to a decision, lodged with the body that took it, within six weeks. |
| **BRP** | Basisregistratie Personen, the Dutch personal records database. |
| **BSN** | Burgerservicenummer, citizen service number. The test cases use test numbers such as `000000012`. |
| **DPIA** | Data Protection Impact Assessment under the GDPR. |
| **Eenhoofdig ouderlijk gezag** | One parent has gezag. |
| **EUPL** | European Union Public Licence, the licence of RvIG's code and specifications. |
| **Gegeven / Als / Dan** | Given / When / Then, the steps of a Gherkin scenario in Dutch. *Functionaliteit* is Feature, *Regel* is Rule, *Voorbeeld* is Example, *Achtergrond* is Background, *Abstract Scenario* with *Voorbeelden* is a Scenario Outline with Examples. |
| **Gezag** | Parental authority over a minor: care, upbringing, legal representation. |
| **Gezag niet te bepalen** | Outcome: the data are not enough to determine who has gezag. Comes with a *toelichting*. |
| **Gezagsregister** | Public register in which courts record decisions on gezag and guardianship. |
| **Gezamenlijk gezag** | A parent and someone who is not a parent have gezag together. |
| **Gezamenlijk ouderlijk gezag** | Both parents have gezag together. |
| **IAMA** | Impact Assessment Mensenrechten en Algoritmes, a human rights impact assessment for algorithms. |
| **Kenbaar** | Knowable: the person concerned can know and follow the reasoning of a decision. |
| **LARS** | The register's number for a registration, in its URL and API, for example 61781447. |
| **MijnOverheid** | The government's personal portal for residents, with a message box. |
| **Motivering** | The statement of reasons of a decision. |
| **RNI** | Registratie Niet-ingezetenen, the part of the BRP for people who do not live in the Netherlands. |
| **RvIG** | Rijksdienst voor Identiteitsgegevens, the agency that manages the BRP and runs the BRP API. |
| **Terugmelding** | A report by a user organisation that it doubts the correctness of information it received from the BRP. |
| **Tijdelijk geen gezag** | Outcome: nobody can exercise gezag at the moment. Comes with a *toelichting*. |
| **Toelichting** | The explanation the algorithm gives with some outcomes. |
| **Voogdij** | Guardianship: gezag of someone who is not a parent, possibly an organisation. |
